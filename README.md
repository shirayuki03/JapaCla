# JapaCla

JapaClaは、Clambonの予約語を日本語で書けるようにするソース変換型拡張です。
英語の予約語と日本語の予約語は、同じプログラム内で併用できます。

## Web UIでの使い方

1. このディレクトリを公開GitHubリポジトリへ配置します。
2. Clambon Web UIの拡張機能画面へ、リポジトリまたはこのディレクトリのURLを入力します。
3. プログラムの先頭に `import JapaCla` を書きます。

```clambon
import JapaCla

変数 score = 乱数(1 から 3)
印刷(score)
```

文字列内の日本語は変換されません。変数名と関数名は、現在のClambonと同じ英数字の名前を使用してください。
自然対数の底は日本語化せず、`e` と書きます。
